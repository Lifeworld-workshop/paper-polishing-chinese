# 中文学术硬规则（可执行判定）

本文件为 `paper-polishing-chinese` 的硬规则细化清单。出现命中项时，应优先执行修正。

## R1. 假设（assumption）与研究假说（hypothesis）不得混用

- `假设`：模型前提、识别前提、理论设定（如“平行趋势假设”）。
- `研究假说`：可被数据检验的命题（如“数字化转型提升企业生产率”的命题）。

判定规则：

1. 句子在提出“待检验命题”时，用“研究假说”。
2. 句子在说明“方法前提/理论前提”时，用“假设”。
3. 同一段落若同时出现两者，必须保持角色分工清晰。

示例：

- 不推荐：`本文提出如下假设：数字化转型显著提升就业质量。`
- 推荐：`本文提出如下研究假说：数字化转型显著提升就业质量。`
- 不推荐：`在平行趋势研究假说成立时，DID 估计有效。`
- 推荐：`在平行趋势假设成立时，DID 估计有效。`

## R2. “阐释”与“阐述”用法区分

- `阐释`：强调解释内涵、机制、精神、意义。
- `阐述`：强调完整展开观点、过程、事实脉络。

判定规则：

1. 宾语若为“精神、内涵、机制、含义”，优先用“阐释”。
2. 宾语若为“观点、过程、政策框架、研究设计”，优先用“阐述”。

示例：

- 推荐：`阐释该政策的激励机制。`
- 推荐：`阐述本文的识别策略与估计步骤。`

## R3. 禁用空泛强化词

判定规则：

1. 出现“系统性”“系统地”等空泛强化词时，默认视为需改写。
2. 若作者意在强调范围、层次、路径或覆盖面，必须直接写出对应对象，不用抽象强化词代替。
3. 改写后应让读者看出“具体在哪些维度、何种层面、什么条件下成立”。

示例：

- 不推荐：`本文系统地讨论了制造业转型的影响机制。`
- 推荐：`本文从劳动力需求、家庭教育投入与城市就业结构三个维度讨论制造业转型的影响机制。`

## R4. 制造业主题术语偏好

判定规则：

1. 涉及本文主题及相近经济学语境时，优先使用“制造业转型”。
2. 仅在直接引用文献原文、政策原词或需要区分“升级”与“转型”两个概念时，保留“制造业升级”。
3. 若改写会改变原作者概念边界，应保留原词并提示用户该处属于概念性差异，而非单纯风格替换。

示例：

- 不推荐：`制造业升级改变了城市教育机会结构。`
- 推荐：`制造业转型改变了城市教育机会结构。`

## R5. 区域协同研究的审慎表述

判定规则：

1. 地方政府与市场关系，优先表述为“地方政府对市场有话语权”，避免“控制力”。
2. 产能配置可讨论“协同”。
3. 交通、能源可讨论“一体化”，通常作为协同发展的前提条件。
4. 教育议题不宜直接宣称“一体化已可行”，需交代现实约束与推进难度。

可直接入文示例：

- `在区域协同框架下，地方政府对市场仍具有显著话语权。`
- `产能配置的跨区域协同是实现要素优化配置的重要抓手。`
- `交通与能源网络的一体化是区域协同发展的基础条件。`
- `教育资源配置受制度与治理边界约束，短期内难以实现实质性一体化。`

## R6. 文献分歧连接词

判定规则：

1. 当作者之间存在不同看法时，需显式使用转折/对照连接词。
2. 推荐优先词：`然而`、`相反地`、`从另一方面来说`、`虽然如此`。
3. 不限于上述四项，但语义关系必须清晰。

示例：

- `已有研究强调财政激励的正向作用；然而，近期证据显示其边际效应随治理成本上升而减弱。`

## R7. 比较研究必须量化

判定规则：

1. 进行 A 与 B 比较时，不得只写“更高/更低/更强/更弱”。
2. 必须补充可审计数值：差值、倍数、百分点、区间或变化率。

可用模板：

- `A 比 B 高出 12.4%`。
- `A 是 B 的 2.3 倍`。
- `A 较 B 高 6.8 个百分点`。
- `A 的增长率约为 B 的 1.9 倍`。

## R8. 禁忌用语分级执行

- A 级（绝对禁用）与 B 级（谨慎使用）见 `references/prohibited-wording.md`。
- A 级命中：直接改写。
- B 级命中：先判断语境是否满足保留条件，不满足则改写。

## R9. 程序性免责句不得进入定稿

判定规则：

1. 命中“后续若官方发布更新数据”“后续如有新口径”“不影响本文论证”“此处暂以现有数据为准”等程序性说明时，视为定稿禁留。
2. 该类内容属于写作过程说明、版本说明或自我免责说明，不属于论文论证链条。
3. 处理方式为直接删除；如确需保留工作说明，仅允许移至作者内部备注或文外沟通，不得留在正文、脚注、尾注或附注中。

示例：

- 不推荐：`若后续官方发布更新数据，则以更新数据为准，但不影响本文论证。`
- 推荐：直接删除，不留入文。

## R10. 政策脚注必须使用正式来源

判定规则：

1. 涉及政策文件、法律法规、国务院文件、部委通知、人大文件、新华社政策稿件时，脚注链接应优先使用正式原始来源。
2. 推荐来源包括：国务院网站、中央人民政府门户网（`gov.cn`）、全国人大官网、新华社官网，以及相关部委官网。
3. 驻外使馆镜像链接、转载页、二次搬运页不得作为定稿脚注来源。
4. 若暂时无法核验正式来源，删除镜像链接并单独提示用户补核，不得把非正式链接留在论文定稿中。

可直接执行示例：

- 不推荐：脚注引用驻外使馆页面转载的政策全文。
- 推荐：改引国务院或 `gov.cn` 的原始政策发布页；法律条文优先改引全国人大官网文本。

## R11. 实证模型解释不得暴露代码字段名，且必须解释符号脚标

第一性原则：论文正文面向读者解释“经济对象、统计口径和识别含义”，不是展示数据文件或程序实现。代码字段名属于机器可读标识，不得替代自然语言定义；公式符号属于论文内部契约，第一次出现时必须说明每个符号和脚标对应的个体、地区、时间、组别或批次。

判定规则：

1. 解释变量、被解释变量、控制变量或机制变量时，不得写入数据表字段名、程序变量名或下划线命名的代码标识；除非用户明确要求整理代码口径附录，正文、脚注、表注和变量解释均改为自然语言。
2. 若原文出现“某公式符号对应数据中的某字段名”一类句式，直接改写为“该符号表示什么经济含义、如何构造、取值越大意味着什么”。
3. 比值型变量必须说明分子和分母；0/1 变量必须说明 1 和 0 分别代表什么；连续变量必须说明数值方向。
4. 实证模型设定说明中，每个符号和脚标第一次出现时必须解释含义，包括个体、城市、出生队列、年份、行业、职业、教育阶段城市等维度。
5. 脚标字母必须与正文基准回归或同一节既有设定保持一致，不得临时新增、换字母或改变同一脚标含义；若基准设定不清，先提示用户确认。
6. 核心系数解释必须回到研究问题：说明该系数衡量何种处理变量变化下，不同群体或不同对象的相对结果变化，不得只说“关注的核心系数是某个希腊字母”。

示例：

- 不推荐：`其中，M 表示数据中的某代码字段名。`
- 推荐：`其中，M 表示个体进入职业的高等教育密集程度，按该职业类别中专科及以上受教育程度劳动者占该职业有效就业人口的比例衡量；数值越大，说明该职业类别越集中于高等教育劳动者。`
- 不推荐：`核心解释变量为 S，F 为性别虚拟变量。`
- 推荐：`S 表示个体教育决策窗口内所在城市中高技术制造业出口额占制造业出口总额的平均份额；F 取值为 1 表示女性，取值为 0 表示男性。`
- 推荐：`脚标 i 表示个体，c 表示教育阶段城市，b 表示出生队列；若同一节基准模型已使用其他脚标，应沿用基准模型的脚标设定。`

## 快速核查清单

- 是否混用了“假设/研究假说”？
- 是否误用了“阐释/阐述”？
- 是否出现“系统性”“系统地”等空泛强化词？
- 是否将“制造业升级”误写为应使用“制造业转型”的场景？
- 是否将“话语权”误写为“控制力”？
- 比较句是否给出数值？
- 文献分歧处是否有清晰连接词（含“相反地”写法）？
- 是否保留了“若后续官方发布更新数据……”一类程序性免责句？
- 政策脚注是否已统一为正式来源，且不存在驻外使馆镜像链接？
- 实证模型解释是否仍暴露数据字段名或程序变量名？
- 公式中每个符号和脚标是否已用自然语言解释，且与基准设定一致？
- 是否存在 A 级禁忌用语？
