# 文献引用与主张信息密度

本文件用于防止学术写作以“存在差异”“产生影响”“相关条件”等抽象词替代文献的实际发现。适用于文献综述、Introduction、理论机制、研究贡献及任何带引文的改写。

## 1. 最小信息单元

引用经验研究时，每项结论至少写清以下三项：

1. **研究主体或比较对象**：谁与谁比较，或哪类学生、家庭、地区受到影响。
2. **方向**：增加、降低、偏向、集中于、早于、晚于，或哪一方更高。
3. **具体结果**：教育投入、升学概率、学业表现、工资回报、职业选择等。

只有原文明确提出或检验机制时，才补充第四项：

4. **渠道**：养老支持、收入分享、风险态度、资源竞争、学业表现等。

理论文献也要说明模型中谁作出何种选择、关键参数如何变化、结果方向如何。不得用“相关机制”概括已经可以具体表述的理论关系。

## 2. 抽象词落实规则

下列表述不得单独承担文献结论：

- 存在差异
- 产生影响
- 考虑相关条件
- 改变家庭决策
- 影响后续结果
- 通过某种机制发挥作用
- 与教育获得有关

出现上述表达时，在同一句或下一句回答：

- 差异发生在哪些主体之间？
- 哪一方更高、更低、增加或减少？
- 具体影响哪个结果？
- 文献实际提出或检验了哪条渠道？

## 3. 引用前核验

写作前为每篇文献建立内部“主张卡片”，至少记录：

| 字段 | 内容 |
|---|---|
| 文献 | 作者与年份 |
| 已核来源 | 摘要、全文或阅读笔记 |
| 研究对象 | 国家、样本、群体或制度背景 |
| 具体发现 | 主体、方向和结果 |
| 机制状态 | 已检验、仅讨论或未涉及 |
| 适用边界 | 相关性、因果性、一般效应或性别特有效应 |

不得仅凭论文标题推断研究结论。无法核验具体发现时，将文献保留在内部引用清单中并标记待核；核验完成后再写入正文。

## 4. 多篇文献分组

- 只有支持同一个具体命题且方向一致的文献可以合并引用。
- 研究对象、方向、结果或机制不同的文献拆开叙述。
- 每句话承载一个主要的可检验命题。文献数量较多时，优先增加信息句，避免在一个抽象句末集中堆放引文。
- 原有引文需要保留时，可以拆分组合或移动到更匹配的段落。每篇文献仍须支持紧邻它的完整主张。

## 5. 证据边界

- 一般学生样本中的学习、营养或健康效应不能直接改写为女性特有效应。
- 文献没有比较男女时，明确其只提供一般性渠道证据。
- 相关性研究不能改写为因果效应。
- 作者提出但未检验的机制写为“解释”或“可能渠道”，不能写成已获得实证支持的机制。
- 研究只支持结果方向时，不额外补写原文没有讨论的动机、偏好或行为渠道。

## 6. 紧凑叙述模板

单篇经验研究优先采用：

> 作者使用何种样本或制度背景，发现 A 相对 B 出现何种方向的结果；作者将其与何种渠道联系起来。

多篇方向一致的研究优先采用：

> 文献 A 和 B 均发现具体结果及方向；文献 C 进一步说明该结果在哪种条件下更强或更弱。

不要机械填满模板。样本信息与当前论点无关时可以省略，但主体、方向和结果必须保留。

## 7. 对照示例

不合格：

> 家庭对儿女的教育回报预期存在差异。

合格：

> 父母预期从儿子获得更多养老支持和收入分享，因此对儿子教育投资回报的评价更高，并在较低的大学成功概率下为儿子选择普通高中。

不合格：

> 男女在认知和非认知能力上的差异影响高等教育获得。

合格：

> Jacob（2002）认为，女生在非认知技能上的相对优势，以及男生未接受大学教育时较高的劳动市场回报，共同提高了女性相对于男性继续升学的概率。

不合格：

> 营养条件改善促进了女性教育获得。

合格：

> 相关研究发现，较高的饮食质量和稳定的早餐摄入能够改善学生的学业表现；这些研究说明营养影响学习结果，但没有直接证明女孩获得了更大的改善。

## 8. 交付前逐句核查

检查所有带引文的句子：

1. 删除作者年份后，读者能否知道谁与谁比较？
2. 句子是否给出明确方向和具体结果？
3. “差异、影响、条件、机制、渠道”等词是否已落实为具体内容？
4. 每篇文献是否支持紧邻它的完整主张？
5. 是否把一般效应误写成性别效应？
6. 是否把相关性、理论解释或未检验渠道写成因果机制？

默认在内部完成核查，只向用户交付连续、简洁且可直接入文的学术叙述；用户要求时再输出主张卡片或逐项引用台账。
