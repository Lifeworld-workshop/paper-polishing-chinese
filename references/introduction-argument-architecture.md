# Introduction 论证架构

本文件用于撰写、重写、压缩或重组经济学及社会科学论文的 Introduction。目标是让开篇现象、研究谜题、文献缺口、制度或冲击、识别设计、主要结果和贡献围绕同一决策节点与传导链展开。

## 1. 基本原则

- 先核对全文实际研究对象、结果变量和识别范围，再安排 Introduction。
- 先搭建段落功能和论证顺序，再处理词句。
- 只使用正文已经检验或有文献支持的主张，不在 Introduction 新增未经支持的结果和机制。
- 将理论机制、经验设计与贡献写成同一研究问题的不同层面，避免各段分别讲述互不衔接的故事。

## 2. 开篇现象与结果范围

开篇经验事实应覆盖论文的核心结果领域。论文同时研究教育、就业或职业结果时，开篇需要说明这些结果为何属于同一问题链条，并在后文分别给出对应结果。

执行检查：

1. 列出正文所有核心结果及其分析层次。
2. 检查开篇是否遗漏后文重点解释的结果领域。
3. 检查开篇是否承诺正文没有检验的结果。
4. 用事实、趋势或制度变化界定问题范围，避免仅用宽泛价值判断开场。

## 3. 研究谜题与决策节点

研究谜题应落实到可观察、可识别、可建模的决策节点。宽泛趋势可以提供背景，核心问题还需说明变化发生在哪个选择、约束或配置环节。

一个完整的研究问题通常包含：

- 需要解释的经验变化；
- 产生变化的政策、冲击或机会条件；
- 个体、家庭、企业或政府作出选择的关键节点；
- 论文实际考察的中间结果与最终结果。

如果决策节点在数据中无法观察，或识别设计无法对应，应降低表述强度并说明证据边界。

## 4. 文献组织与缺口提炼

按理论解释、结果领域或因果环节组织文献。每组文献都要回答一个具体问题，并为研究缺口提供必要背景。

优先采用以下顺序：

1. 概括已有研究对核心现象的主要解释。
2. 说明每类解释覆盖的主体、方向和具体结果。
3. 指出已有研究尚未连接的决策节点、传导环节或结果层次。
4. 引出本文可用于检验该缺口的制度环境和识别设计。

避免逐篇连续摘要、按作者名单排列文献、在段尾集中堆放无法共同支持同一主张的引文。具体引文规则同时遵循 `citation-claim-density.md`。

## 5. 传导链

在内部先重建全文的最短传导链：

```text
政策或外生冲击 -> 关键决策节点 -> 中间结果 -> 最终结果
```

链条可以包含机制条件，但每一环都要标明证据状态：直接估计、异质性支持、间接一致或理论解释。缺少直接检验时，使用“与该机制一致”“可能渠道”等边界清楚的表述。

检查以下对应关系：

- 研究问题是否点明关键决策节点；
- 制度背景是否解释冲击如何改变该节点的约束或回报；
- 识别设计是否利用与该冲击一致的变异；
- 结果段是否按链条顺序报告估计；
- 贡献段是否说明本文补上了哪一段关系。

## 6. 段落功能

常见的 Introduction 顺序如下，可按篇幅合并相邻功能：

1. 经验事实与研究谜题。
2. 相关解释、文献边界与研究缺口。
3. 制度背景及其与研究问题的连接。
4. 数据、识别设计和关键识别假设。
5. 主要结果、稳健性与机制证据。
6. 相对既有文献的贡献。
7. 文章结构安排，期刊不要求时可以省略。

每段设置一个主要任务。段末应推动下一段进入新的论证环节，避免重复总结同一缺口或制度优势。

## 7. 理论模型预告

保留理论模型时，只在 Introduction 中说明模型处理的关键选择、核心参数变化和可检验预测。详细设定留在理论部分。模型预告可以放在研究设计之后，或嵌入机制贡献，具体位置取决于模型对识别和结果解释的重要性。

## 8. 表述边界

- “理想实验环境”“填补空白”“首次发现”“普遍忽略”等强断言需要充分的文献检索或识别依据。
- 制度改革规模大不自动构成外生变异；说明具体变异来源及其识别假设。
- 中间结果与最终结果存在时间顺序时，不自动推断因果中介关系。
- 贡献应落到新增的研究对象、关系、识别证据或机制含义，避免只改写主要结果。
- 开篇趋势来自图形或描述统计时，使用描述性动词；“得益于”“促进”“推动”“驱动”等归因词需有相应识别证据。
- 指标简称不得丢失比较方向。首次使用比例、性别比、群体差距或相对变化时，说明分子、分母、基准组或差值定义。
- 结果标签保持与数据口径一致，不为提高表达力度增加“白领”“优质”“高级”等未经测量的属性。
- 机制概念保持具体；已知渠道为收入分享、养老支持、风险态度或容量约束时，不压缩为“经济联系”“相关机制”等宽泛词。
- “突破瓶颈”“重塑”“解锁”“跃升”等修辞性动词应回到可观察选择、结果方向和估计量级。

## 9. 交付前检查

- 开篇是否覆盖全部核心结果领域？
- 研究谜题是否落到可识别的决策节点？
- 文献是否围绕具体主张和研究缺口组织？
- 传导链的每一环是否有明确证据状态？
- 制度背景是否自然引出识别设计？
- 主要结果是否逐项回应研究问题？
- 贡献是否说明本文新增了哪段关系或证据？
- 是否存在重复缺口、重复制度背景或未经检验的结果承诺？
- 指标简称是否保留分子、分母、基准组和比较方向？
- 描述性证据是否使用了超出识别强度的因果或归因动词？
- 机制词是否具体，结果名称是否与数据口径一致？
- 强调词和修辞性动词是否提供了新增信息？
