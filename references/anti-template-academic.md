# 学术版反模板化最小集

本文件用于识别中文学术论文中的模板腔、翻译腔和“过度光滑”表达。目标不是“去 AI 味”，而是减少不必要的套写痕迹，让论证更自然、更可审计。

## 1. 使用原则

- 该文件不是硬规则清单，不做机械逐条替换。
- 仅在改动确实提升术语稳定性、句法自然度或论证边界清晰度时才改。
- 若原句虽有风格痕迹，但承载关键辨析功能或作者有意强调，可保留。

## 2. 连接词密度控制

- 同一段内避免连续堆叠“因此、然而、此外、值得注意的是、进一步地”等连接词。
- 若句间逻辑已由语序、主语延续或因果关系自然体现，优先删除冗余连接词。
- 文献综述、机制分析和结果解释中，连接词应服务于论证推进，不作为段落填充物。

## 3. 翻译腔介词链压缩

- 重点识别“基于……进行……关于……的分析”“围绕……展开……的讨论”“对于……作出……的解释”等介词链结构。
- 优先改为主谓清楚、动作明确的中文表达，例如把抽象名词结构改为具体动词结构。
- 压缩的是虚词和空转结构，不是强行把所有句子改短。

## 4. 升维词谨慎使用

- 对“本质上”“归根结底”“真正的”“核心在于”等升维词保持谨慎。
- 只有在前文已经给出概念边界、识别条件或文献依据时，才保留这类表述。
- 若只是把普通经验结论拔高为终极判断，优先改为“主要表现为”“更直接地说”“在本文语境下”。

## 5. 论证边界显化

- 结果陈述尽量同时说明适用范围，例如样本、时期、地区、识别条件或比较基准。
- 对“显著提高了”“明显改善了”“证明了”等满结论表达，优先补充边界条件，再决定是否降调。
- 对机制句和政策含义句，避免从局部结果直接跳到普遍断言。

## 6. 执行提醒

- 发现模板腔时，先判断它影响的是术语、句法还是论证边界，再决定怎么改。
- 若修改会削弱必要的学术辨析、文献对话或段落承接，则宁可保留，不做“去模板化表演”。

# 概念边界检查最小集

本文件用于识别中文学术论文中“概念未界定、术语角色滑动、机制句空转”的问题。目标不是扩写理论，而是在润色前先确保概念站得住。

## 1. 使用原则

- 该文件属于默认扫描项，但不是硬规则清单。
- 若概念不清会影响事实口径、变量含义或机制方向，先提示澄清，不抢先改写。
- 概念检查优先于句法润色；先把“说的是什么”弄清，再处理“怎么说更顺”。

## 2. 核心概念先定义再润色

- 段落中首次出现的核心概念，应尽量交代它在本文中的具体含义、口径或层次。
- 对“制造业转型”“高等教育获得”“出口结构升级”“性别差距”等高负载概念，优先确认其在当前段落中是指标、现象、机制还是研究对象。
- 若作者尚未给出定义，润色时不要擅自补出新的概念边界。

## 3. 术语角色不滑动

- 同一术语在同一节内应保持稳定角色，不得在变量、现象、机制、政策口号之间来回滑动。
- 若一处写的是可度量变量，另一处写的是宏观现象或解释机制，应显式拆开，而不是继续沿用同一词面。
- 发现“同词异义”时，优先提示用户澄清当前口径，再决定如何改写。

## 4. 大词空转检测

- 对“发展逻辑”“内在机理”“关键抓手”“根本路径”“深层原因”等抽象大词，先判断去掉后是否损失实质信息。
- 若不损失，优先改写为可观察对象、行为关系、指标口径或具体机制。
- 若必须保留抽象概念，后文应尽快落到可检验或可描述的内容上。

## 5. 机制句必须落地

- 机制句应尽量回答“谁通过什么渠道影响了什么结果”。
- 对“通过……进一步促进……从而提升……”这类连续抽象动词链，优先拆成具体主体、渠道和结果。
- 若机制句本质上只是把结果换词重说，应压缩或重写，避免伪机制。

## 6. 执行提醒

- 遇到概念冲突时，先判断这是定义问题、口径问题还是层级问题。
- 若修改会越过作者原本的理论边界，只提示风险，不代替作者重建概念体系。
